# Alcance de plataformas y conexiones

Decisiones del dueño, 24-10-2026, durante la continuación de fase A:

- La entrega inicial se centra en macOS Apple Silicon.
- El dueño eligió inicialmente macOS e iPhone y después indicó expresamente:
  «la app para el iphone dejemoslo para otra ocasion». iPhone queda aplazado.
- Android, Windows y una distribución de escritorio Linux quedan para decisiones
  posteriores. Las pruebas del núcleo en Linux no acreditan un cliente Linux.
- Telegram es el primer canal externo elegido. Los demás canales conservan su
  inventario y no se activan automáticamente.
- La inferencia sigue siendo Codex con ChatGPT mediante el cliente oficial. No se
  incorporan proveedores alternativos, embeddings ni voz remota por ese hecho.

Esto cambia la prioridad y los destinos de esta entrega, no convierte capacidades
ausentes en implementadas ni cierra la matriz universal de referencia. La fase B
de herramientas adicionales de Jarvis sigue esperando el cierre acordado de A.

La futura app compañera de iPhone necesitará conexión cifrada, emparejamiento y
revocación explícitos. No se publica un puerto ni se anuncia esa conexión como
disponible en la versión actual.
