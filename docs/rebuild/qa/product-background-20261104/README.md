# Fuentes del comprobador de aislamiento

Snapshot propio del caso finito de Jarvis del 4 de noviembre de 2026. Conserva
los scripts revisados, su admisión, límites, hashes y guía. No forma parte del
runtime de Jarvis ni aporta por sí solo evidencia de ejecución. Los resultados
se registran por separado en `PHASE_A_PRODUCT_COORDINATION_QUALIFICATION.json`.

La raíz original declarada es `/private/tmp/jarvis-product-background-20261104`.
Estas copias son de consulta: no ejecutar desde este directorio ni reutilizar una
intención de arranque o respuesta. Otro caso requiere una raíz nueva, revisión y
admisión propias, CI exacta aprobada y nueva cuota/plazo.

No se incluyen el perfil, la clave de cliente ni las credenciales de cuenta. Los
recibos exportados posteriormente deben estar saneados. El intento histórico de
seis etapas permanece incompleto; este caso independiente verifica sólo el hueco
de B mientras A espera y su aislamiento al terminar.
